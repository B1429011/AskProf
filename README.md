# AskProf｜師生協作平台

這是 Codex 跨域創造黑客松的可操作網站原型，整合：

- 專輔預約、取消與提醒
- 教授探索與可預約時段
- 每學年系必修／系選修課表
- 個人已修、進行中與未修狀態
- 教授端新增、暫停與重新開放時段
- 長庚官方公開系所目錄與師資專長資料
- 全校 44 個學術系所／學程，加上通識中心 4 個學科的公開師資搜尋索引，並以官方公開信箱對應教師資料

## 本機預覽

```text
cd app
node server.mjs
```

開啟 `http://127.0.0.1:4173/`。

## GitHub Pages

## 公開資料來源

`app/data/cgu_public.json` 由 `tools/fetch_cgu_public_data.py` 從長庚大學官方系所目錄與系所師資頁面整理，包含系所網址、教師姓名、職稱、公開專長、信箱與官方個人頁面連結。重新抓取時請先確認官方網站的使用規範，再更新資料檔。

學生個人課表、教師私人行事曆與登入資訊不會放入公開資料檔。學生課表應在登入後由校務系統提供；教授可在教授端自行設定可預約時段。

## 帳號驗證原型與正式部署

首頁現在提供長庚帳號登入畫面：使用者選擇學生／師長、輸入長庚學校信箱，再輸入一次性驗證碼後才能進入平台。原型會在畫面顯示測試碼，方便黑客松展示；測試碼不會寄信，也不代表已完成校方身分查核。

GitHub Pages 是靜態網站，不能安全地寄送 Outlook 信件、保存密碼或查詢校務身分。正式環境應由後端接上長庚 Microsoft Entra ID／校務 SSO，使用 OIDC 驗證回傳的學校帳號與角色，再以短效 session 或安全 cookie 回傳前端。網站不應自行收集長庚密碼，也不應把驗證碼或身分資料放入公開前端檔案。

師資資料目前由 `app/data/cgu_public.json` 整理全校 44 個學術系所／學程與通識中心 4 個學科，共 629 筆公開教學師資；其中 552 筆有官方公開信箱。資料也包含校方公開分機目錄中的通識中心教師（例如何金龍教授，分機 3794）。師長登入原型會先用信箱比對這份官方資料，顯示對應的教師姓名與系所，再進入驗證碼流程。正式身分驗證仍必須由校方 SSO 確認。

「專輔專區」依長庚大學 2024/06/21 公開的「預約專業科目輔導員」公告整理，共 7 位輔導員，顯示公告中的輔導科目、信箱、分機與諮詢地點。可預約時段則由輔導員登入後自行維護。

## 正式 AI 學習分析

個人學習檔案的分析流程已改為呼叫 `backend/server.mjs` 的安全 API 代理，再由後端連線長庚 CGU LLM Gateway；目前預設模型為 `gpt-5.6-luna`。瀏覽器只送出學生主動填寫的回饋、預約主題與修課狀態，不會接觸 LLM API Key。後端會回傳結構化的摘要、各科目狀態與下一步建議，並在瀏覽器依登入帳號分開保存。

GitHub Pages 本身不能執行後端，因此正式環境要把 `backend/` 部署到可保存 secrets 的 Node 雲端服務，設定 `CGU_API_KEY`、`CGU_MODEL` 與 `ASKPROF_ALLOWED_ORIGIN`，再把網站的 `ASKPROF_AI_ENDPOINT` 指向該服務。沒有後端時，網站會顯示「AI 分析連線失敗」，不會假裝已完成真正分析。啟動方式與部署變數請看 [`backend/README.md`](backend/README.md)。

學生端與教授端使用不同工作區：個人學習檔案與修課地圖只在學生端顯示；教授端聚焦公開資料、可預約時段與學生預約管理。
