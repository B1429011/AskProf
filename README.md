# 學習導航｜師生協作平台

這是 Codex 跨域創造黑客松的可操作網站原型，整合：

- 專輔預約、取消與提醒
- 教授探索與可預約時段
- 每學年系必修／系選修課表
- 個人已修、進行中與未修狀態
- 教授端新增、暫停與重新開放時段
- 長庚官方公開系所目錄與師資專長資料

## 本機預覽

```text
cd app
node server.mjs
```

開啟 `http://127.0.0.1:4173/`。

## GitHub Pages

此專案已附上 GitHub Actions 工作流程。將專案推到 GitHub 的 `main` 分支後，GitHub Actions 會自動把 `app/` 發佈成網站。

GitHub Pages 網址：`https://b1429011.github.io/app-for-cgu/`

## 公開資料來源

`app/data/cgu_public.json` 由 `tools/fetch_cgu_public_data.py` 從長庚大學官方系所目錄與系所師資頁面整理，包含系所網址、教師姓名、職稱、公開專長、信箱與官方個人頁面連結。重新抓取時請先確認官方網站的使用規範，再更新資料檔。

學生個人課表、教師私人行事曆與登入資訊不會放入公開資料檔。學生課表應在登入後由校務系統提供；教授可在教授端自行設定可預約時段。
