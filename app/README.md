# 學習導航｜師生協作平台 Demo

這是一個可操作的前端原型，對應概念提案中的核心流程：

- 學生端：總覽、教授探索、查看時段、預約／取消、修課地圖、通知
- 教授端：工作台、開放／暫停時段、新增時段、查看學生預約
- 資料：以瀏覽器 `localStorage` 保存預約與目前角色，重新整理後仍會保留

## 開啟

在 `app` 資料夾執行：

```text
node server.mjs
```

再開啟 `http://127.0.0.1:4173/`。

目前使用示範資料，尚未串接校務系統、正式登入、Email／Google Calendar 或雲端資料庫；這些是下一階段可接入的服務。
