# 學習導航｜師生協作平台 Demo

這是一個可操作的前端原型，對應概念提案中的核心流程：

- 學生端：總覽、全校官方教授探索、查看時段、預約／取消、修課地圖、通知
- 全校公開資料：系所目錄、官方師資專長與來源連結
- 教授端：工作台、開放／暫停時段、新增時段、查看學生預約
- 資料：以瀏覽器 `localStorage` 保存預約與目前角色，重新整理後仍會保留

## 開啟

在 `app` 資料夾執行：

```text
node server.mjs
```

再開啟 `http://127.0.0.1:4173/`。

公開師資資料位於 `data/cgu_public.json`，來源為長庚大學官方系所網站與校方公開分機目錄，包含 44 個學術系所／學程、通識中心 4 個學科與 629 筆公開教學師資。登入畫面目前是黑客松展示用的 OTP 原型：輸入長庚信箱後，測試碼會直接顯示在畫面上，不會真的寄送 Outlook 信件。正式版本必須由後端接 Microsoft Entra ID／校務 SSO，驗證學生或師長角色後再建立安全 session；GitHub Pages 前端不收集學校密碼，也不保存學生個資。

專輔專區另外整理長庚大學 2024/06/21 公開的「預約專業科目輔導員」公告，共 7 位輔導員與公告中的聯絡資料，並使用同一套可預約時段資料結構；輔導員登入後可新增專輔時段。
